## 0.6 维护功能

新增系统归档网页恢复、AX1800 固件上传升级及恢复出厂，复用 uhttpd/rpcd、ucode、sysupgrade 和设备已有工具，不增加常驻服务。上传使用固定私有目录、随机令牌、顺序分块及 SHA-256 校验；归档检查设备与版本清单、tar 头、路径、类型、重复成员和体积。取消及页面卸载尝试删除临时数据，10 分钟后令牌失效，下次上传请求清理过期文件。

## 本轮实现与验证

0.5 增加独立 `/settings/wan/` 和 `/settings/dhcp/`，复用现有 `network` / `dhcp` UCI 权限及确认回滚流程，不增加设备端后台服务。旁路由隐藏这两个菜单，直接访问也不会开放编辑。WAN 保留网口、VLAN、MTU、MAC 和独立 IPv6 接口；密码留空保留已有凭据，切出 PPPoE 时清理旧凭据。静态 WAN 校验 LAN 网段冲突、网关和 DNS。PPPoE 校验输入与配置暂存，不模拟运营商认证。

DHCP 使用实际起止 IP，验证可用网段、路由器地址、地址数量和租期；关闭 IPv4 DHCP 时保留 IPv6 字段和静态租约。缩小 LAN 网段前检查地址池，离线的静态 WAN 同样参与 LAN 冲突校验。网络备份格式 v2 增加 DHCP，并兼容 v1；同次恢复 LAN、地址池、DNS 和无线，仍使用同一个回滚事务。备份不包含 WAN 及宽带账号密码。

## CI 与后续顺序

普通 push / pull request 只自动运行快速检查，同分支新提交会取消旧检查。配置解析、QEMU 和完整固件构建均手动启动；完整构建复用模拟作为前置检查。安装依赖步骤设置独立限时，减少网络卡住时占用 runner。开发时先本地检查、集中推送，避免反复运行完整编译。
