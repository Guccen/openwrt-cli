# 网络配置与备份恢复

[返回项目首页](../README.md) · [首次使用](getting-started.md) · [系统维护与独立更新](maintenance.md)

## 支持的设置

- LAN：修改 IPv4 地址和子网掩码；旁路由还可修改上游网关。会保留桥接、WAN 及其他现有字段；如果旁路由 DNS 仍跟随默认网关，网关修改时同步更新。
- WAN：主路由支持自动获取、静态 IPv4、PPPoE 拨号和上游 DNS。宽带密码留空保留，切回其他上网方式时清除旧拨号凭据；保留当前网口、VLAN 及独立 IPv6 接口。N1 默认 USB WAN，也可在无线设置切换接线方案，详见[N1 无线说明](n1-wireless.md)。
- DHCP：主路由支持 IPv4 地址分配开关、起止地址和租期，保留静态租约及 IPv6 设置。地址池不能包含路由器地址；缩小 LAN 网段前，先调整地址池使其仍位于新网段内。
- DNS：支持最多 4 个 IPv4/IPv6 上游地址。留空恢复自动 DNS。现有域名定向 DNS 等高级规则应通过 SSH 管理。
- 无线：AX1800 按实际频段显示 2.4 GHz、5 GHz 独立卡片，可分别修改 AP 的启用状态、SSID、WPA2/WPA3 兼容加密、密码和隐藏状态。两种频段可以使用相同或不同名称；已有密码不会填入输入框，留空保留。频段按设备配置识别，不根据 radio 编号猜测；企业认证、客户端等高级接口不开放编辑。
- 备份与恢复：导出 LAN、DHCP 地址池、上游 DNS 和支持的无线 AP 设置为 JSON；选择同型号、同主/旁路由模式的备份，预览差异后恢复。格式 v2 增加 DHCP，兼容 v1 备份，恢复 v1 时保留当前地址池。高级无线接口会明确列出并跳过；不改变 WAN、桥接、无线网络绑定等其他字段，不增加设备写文件或任意命令权限。

## 网络备份格式与范围

网络备份最大 64 KiB，仅在当前浏览器读写。文件包含明文 WiFi 密钥，请妥善保管；预览隐藏密钥。备份不包含 SSH 密钥、设备登录密码、WAN 和宽带拨号凭据、DNS 域名定向规则及其他系统配置。存在高级 LAN、DHCP 或不支持的 DNS 策略时需使用 SSH 管理备份。恢复和普通配置修改共用设备端的确认回滚流程。

## 应用确认与回滚

点击应用前先检查输入，再确认开始 120 秒计时。LAN 地址变化时，使用“打开新地址并确认”按钮，在新页面检查连接后保留设置。页面通过校验来源和窗口的 `postMessage` 传递当前短期会话，令牌不放入 URL 或 localStorage；目标标签页仅把短期 SID 写入自身 sessionStorage，以便刷新时重新向设备验证。若换了网段，需要重新连接网络；新地址可能需要确认设备证书。

选择“恢复原设置”可主动回滚。关闭页面或失联后，不需要浏览器继续运行，设备会在未确认时回滚。rpcd 的回滚快照和计时器位于内存，**应用期间不要重启、断电或更新系统服务**；这类中断不保证自动恢复，仍需 SSH 或设备恢复方式。此处使用 [rpcd UCI 接口](https://github.com/openwrt/rpcd/blob/master/uci.c) 的 `apply / confirm / rollback`，不直接提交设置。

## 会话与权限

配置应用期间刷新当前标签页，会恢复原有倒计时和恢复意图；不会重新开始 120 秒计时。页面重新核对设备回滚快照和实际 LAN 地址后才开放确认，不能靠本地记录绕过设备鉴权。事务结束、退出或更换会话后清理记录，设备端回滚仍独立运行。

当前标签页保存短期 rpcd SID 和待确认事务元数据；刷新时先调用设备的会话权限检查，有效才恢复原页面。密码不保存。无效/过期 SID、退出登录、修改密码后会清除；验证时断网不会删除仍可能有效的 SID，可重试。设备端按 900 秒会话超时策略控制有效期，浏览器存储不能绕过设备验证。单个 RPC 权限不足时先核对会话，避免误登出。配置权限限制在 `network`、`dhcp`、`wireless`、`firewall` 四个 UCI 文件，未授予直接 `commit`、任意执行或 `file` 接口；时间设置由固定受限接口处理，不开放 system UCI 写权限。正常页面按需读取；仅在配置待确认期间探测连接。

## 无线运行状态

两款设备的“无线状态”显示射频启用/启动状态、运行接口、实际信道、连接设备 MAC、信号、连接时长及接收/发送协商速率。通过 `network.wireless.status` 和 `iwinfo.info / assoclist` 读取，不授予扫描或断开客户端权限。两款镜像均包含 `rpcd-mod-iwinfo`。N1 接线方案与单射频限制见[N1 无线说明](n1-wireless.md)。
