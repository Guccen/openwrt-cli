# 系统、网络与客户端状态

0.8 增加按需读取的系统状态。设备继续复用 uhttpd/rpcd，不新增常驻服务；手动刷新时才采集，不持续采样 CPU 或扫描客户端。

## 系统概览

保留设备型号、主机名、固件、内核、运行时间、内存与 1/5/15 分钟平均负载。平均负载不是 CPU 使用率。内存占用优先使用内核报告的可用内存，避免把可回收缓存全部算成不可用。

“温度与存储”读取 `/sys/class/thermal/thermal_zone*/temp`，保留驱动提供的传感器名称，最多 16 个。不按序号猜测 CPU/Wi-Fi；缺少传感器显示暂不可用，不生成零值。存储分别读取根目录 `/` 与 `/tmp` 的文件系统容量，显示总计、可用及使用进度，已用达到 90% 时提示清理。可用容量直接使用 df 报告值，不通过总计减去已用推算。临时空间通常使用内存。

设备时间由设备时区格式化，代表采集时刻，不使用浏览器时间替代。上游网络同时展示 WAN/WAN6 和实际承载默认路由的接口，因此 N1 旁路由会显示 LAN 上游。展示协议、设备名、地址、IPv6 委派前缀、网关、DNS 和连接时长。接口 up 和默认路由存在不等于互联网探测成功；本页面不主动发起连通性探测。

## 网络状态

网口卡片展示驱动枚举的以太网设备、链路、协商速率、双工、MAC、累计收发字节。排除回环、无线和没有物理设备/端口标识的虚拟接口。DSA 控制器端口也可能出现，名称来自内核，不假定所有设备都有相同的 LAN/WAN 插孔映射。缺少 carrier、speed 或统计值时分别显示未知、未报告或横线。

收发量是自接口初始化起的累计计数，可能在重启或接口重建后清零，不能当作实时速率。逻辑网络接口仍单独展示。

## 客户端租约

独立地址 `/clients/`，页面进入或手动刷新时才请求租约，概览不会提前读取客户端列表。

- IPv4 使用系统默认 `/tmp/dhcp.leases`，过滤过期、格式错误及重复记录。到期时间 0 代表永久。自定义 leasefile 路径不在本次支持范围内。
- IPv6 使用 odhcpd 的 `dhcp.ipv6leases` 只读方法，展示已绑定的地址和委派前缀、DUID、接口及有效期。未启用服务与空列表分别提示。
- 每种协议最多 512 条，IPv4 文件最多读取 256 KiB；超限会提示来源不可用。
- 剩余租期表示读取时的值，刷新更新。DHCP 租约不是在线检测，静态地址和 SLAAC 客户端可能不在列表中；旁路由提示去主路由查看完整列表。

本轮不增加静态绑定或断开设备操作；这些状态页面保持只读。

## 接口和验证

新增固定 rpcd exec 插件 `router.status`，只开放 `summary`、`clients` 两个读取方法。没有路径、设备名或命令参数；读取固定内核节点、固定挂载点和固定租约来源。前端无法请求任意文件或执行任意命令。扩展状态出错时基本系统概览仍可展示。

本地使用真实 ucode WebAssembly VM 验证租约过滤、IPv6 地址及前缀、存储和内核数据解析，使用 Playwright 验证桌面/平板/手机及旁路由、缺失传感器、不可用 IPv6 来源。QEMU 验证实际安装包、匿名访问拒绝、真实文件系统及 VirtIO 网口、租约文件；不能证明 AX1800/N1 的真实温度、物理端口映射或硬件速率。

数据格式参考 [odhcpd 只读租约接口](https://github.com/openwrt/odhcpd/blob/master/src/ubus.c) 和 [ucode 本地时间定义](https://ucode-lang.org/ucode/module-core.html#localtime)。
