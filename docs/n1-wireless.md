# N1 无线与接线方案

从 0.10.5 起，两种 N1 新镜像包含内置 BCM43455 所需的板级固件、地区数据库、ophub 配套驱动、`wpad-basic-openssl`、`wifi-scripts`、`iw`、`iwinfo` 和受限状态接口。无需另外安装无线软件包。旧镜像仅升级网页不能补回固件和服务，需要重新写入完整镜像。

N1 为单射频，2.4 GHz / 5 GHz 二选一；当前页面仅开放一个热点或一个连接上游的接口，避免依赖未验证的并发模式。N1 使用 WPA2 个人版，不提供强制发射功率、穿墙开关、扫描或断开客户端操作。吞吐、覆盖、不同频段的 AP / STA 能力仍需使用新镜像实机验证，不能把构建成功当作验收通过。

## 主路由

初始管理地址仍为 `192.168.69.1`，内置网口为 LAN。无线默认关闭、不配置共享密码；先通过网线登录，在“无线设置”选择方案。

| 方案          | 上游连接                      | 下游与管理                  | 额外 USB 有线网卡 |
| ------------- | ----------------------------- | --------------------------- | ----------------- |
| USB 网口上网  | 默认 `eth1`                   | 内置 `eth0`＋可选 WiFi 热点 | 需要              |
| WiFi 连接上游 | 内置 WiFi，填写上游名称和密码 | 内置 `eth0`                 | 不需要            |
| 内置网口上网  | `eth0`                        | WiFi 热点                   | 不需要            |

无线连接上游使用路由模式和 DHCP 获取 WAN 地址，不桥接上游与 LAN。现有 `wan6` 通过 `@wan` 跟随链路；是否能获得公网 IPv6 和委派前缀取决于上游。LAN 与上游网段应不同。内置网口作为 WAN 时，必须从 LAN 桥移除，空桥通过 `bridge_empty` 保留管理接口，热点随后加入 LAN。

切换方案会将 WAN 改为 DHCP，清除旧静态地址和 PPPoE 凭据，保留 DNS 等其他参数。切换后若需拨号或静态地址，待连接验证完成再到 WAN 设置修改；无线 WAN 保持 DHCP。镜像中记录自定义 USB 网口名称，切回时按原名称恢复。

应用前确认 WiFi 名称、密码和频段。热点与连接上游相互切换时必须重新输入对应密码，避免把上游密码发布为热点密码。N1 的固定示例无线 MAC 在首次初始化时由本机有线地址派生为稳定、不同的本地单播地址，保留用户后续设置。

所有改动使用现有 UCI 应用、120 秒确认与超时回滚。切换为内置网口上网后，有线管理连接会中断；需在确认时间内连接新热点，再确认保留。若无线未能启动或无法连接，请让设备超时恢复，不要在待确认期间断电。

## 旁路由

管理地址仍为 `192.168.68.2`，只开放 LAN 热点，不切换 WAN，不启用本机 DHCP 与 IPv6 通告。上游路由器负责地址分配，网关与 DNS 按现有旁路由配置使用。网络 JSON 备份包含支持的 AP 名称和密码；无线 WAN 的模式、上游凭据及接线布局不在该备份范围内，按“未包含的高级无线接口”列出。

## 验证与重启问题

本地覆盖了三种接线方案、WAN/LAN 隔离、IPv6 归属、密码切换、禁用保护及频段/信道校验。构建检查必需用户空间包，并在打包结束后检查实际固件、驱动和服务文件，缺失即失败；不把另一套内核的 `kmod-brcmfmac` 装入 ophub 镜像。

WiFi 5 用户空间能力由 `router-ui` 的 ARM64 目标条件依赖选择。上游 `DRIVER_11AC_SUPPORT` 是隐藏选项，仅写入输入 `.config` 会在解析时重置；不能通过关闭校验或安装通用内核驱动绕过。构建产物在校验失败时也保留 `build.config` 和 `resolved.config`。

2026-10-28，旧版 U 盘镜像出现一次软件重启后管理地址和 SSH 长时间不可达、保持原 U 盘断电再上电后恢复的情况。恢复后只读核对根文件系统正常挂载，约 33 秒建立千兆有线链路，未留有上次失败的持久崩溃日志。该现象的根因尚未定位，不能认定已由无线改动修复。若仅执行重启且超过三分钟未恢复，先检查网线和地址，再保持启动 U 盘原位断电约十秒重新上电；仍失败时保留 HDMI 或串口启动记录。升级、恢复、扩容或网络待确认期间不能套用此断电处理。
