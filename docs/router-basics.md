网络配置继续使用 rpcd 的 120 秒确认与超时回滚。设备重启或断电仍不在内存回滚的保证范围内。时间设置即时应用，失败尝试恢复原文件；不开放任意 system UCI 写入。增加的 `coreutils-timeout` 和 `ucode-mod-uci` 只在请求执行时使用，不增加常驻服务。

## IPv6 怎么选

1. 普通主路由优先选自动获取，开启向 LAN 分配地址，请求前缀长度先保持自动。
2. WAN 有 IPv6 地址却没有委派前缀时，先检查上游/光猫是否开放 PD；确认上游支持后可使用中继。不能仅凭一个地址就判定客户端可以上网。
3. 静态方式填写运营商提供的 WAN 地址、网关和独立 LAN 前缀，不要把示例 `2001:db8::/32` 当作真实公网前缀。
4. 旁路由只为自己获取地址，不承担 LAN 的 RA / DHCPv6，避免与主路由竞争。
5. 用诊断页先测试 IPv6 地址，再测试域名，区分路由与 DNS 问题；浏览器应可通过 `[IPv6地址]` 访问 HTTPS 管理。

首次启动在上游没有 ULA 配置时生成设备独有的随机 ULA；不覆盖已有前缀。关闭 IPv6 上网不等于禁用内核 IPv6 和链路本地地址。更改 IPv6 时建议先用 IPv4 地址管理，以便检查和回滚。

## 仍缺少的常见功能

下一批按实际需要补充：访客 WiFi 与内网隔离、静态路由、DDNS、UPnP/NAT-PMP 的受限开关、WPS 以外的便捷接入及接入控制、家长控制/定时规则。IPv6 入站放行也需要独立防火墙规则入口，当前 IPv4 端口转发不能替代它。多 WAN、VLAN/IPTV 和无线中继是更复杂的网络场景，需要独立设计与验收。

UPnP、QoS/SQM、VPN、过滤和 NAS 都可能增加常驻内存或影响加速/吞吐，先保持按需添加。N1 本轮仍通过重写启动介质升级和重置，没有把 AX1800 的闪存流程套用到 N1。
