# 京东云 AX1800 无线调优

[返回项目首页](../README.md) · [网络设置](configuration.md)

目标是兼顾近距离速度、隔墙连接和稳定性。当前固件保留 RE-SS-01 配套 ath11k、无线固件和 NSS；上游默认按硬件能力选择 2.4 GHz 的 20 MHz、5 GHz 的最高 80 MHz，并在硬件支持时启用波束成形。重复写入这些默认参数不能证明提速。

## 本项目的设置

京东云无线设置增加两种带宽预设：2.4 GHz 优先 HE20 / HT20；5 GHz 的“速度优先”优先 HE80 / VHT80，“稳定优先”优先 40 MHz，两者都按当前信道的驱动限制降级。按钮仅填写带宽，保持当前信道和地区，点击“应用射频参数”后仍使用原有 120 秒确认与超时回滚。

发射功率提供“驱动自动”和驱动返回的可选值。“驱动自动”删除手动 `txpower` 限制，最终功率由设备、地区和信道限制决定，不承诺高于原值。修改地区或信道时先使用自动，应用完成后重新读取功率列表。列表不可用时仍可恢复自动，不能填写任意功率。N1 保持原有保守设置，不显示京东云功率控制和预设。

2.4 GHz 可结合现场干扰比较 1、6、11 信道；5 GHz 优先使用驱动允许的 80 MHz，拥挤或远距离不稳定时比较 40 MHz。不要只按附近热点数量判断信道质量。两种频段分别设置名称，便于测速时明确连接对象。远处设备可尝试 2.4 GHz；路由器功率提高不等于手机回传能力提高。

无线状态显示驱动报告的实际运行模式/带宽、包含驱动偏移值的功率和底噪，并在客户端同时返回有效信号、底噪时计算信噪比。信号表示路由器接收到的客户端信号，不是手机测得的路由器信号。缺失数据显示未知，不用配置带宽或硬件支持列表代替运行结果；沿用原有只读请求，无需新增轮询或扫描。

刷入后分别在近距离和常用隔墙位置，用同一终端、同一频段比较信号和协商速率；有线局域网对端测速更适合排除宽带瓶颈。每次只调整一类参数，并记录前后结果。代码检查和固件编译通过均不代表实际吞吐或覆盖已改善。
